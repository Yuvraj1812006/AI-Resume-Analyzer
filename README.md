# 🤖 AI Resume Analyzer

An AI-powered resume analysis application built with **Flutter**, **Node.js**, **Express.js**, and **Google Gemini API**. The application analyzes a student's resume and provides placement-oriented insights, resume scoring, suitable job roles, strengths, weaknesses, and improvement suggestions.

## 📌 Overview

**AI Resume Analyzer** is designed to help college students understand how well their resume is prepared for entry-level software and IT placements.

The application allows users to upload a PDF resume, extracts the text from the PDF, calculates a placement-readiness score, and sends the extracted resume content to a Node.js backend for AI-powered analysis using Google Gemini.

## 📊 Placement Readiness Score

The application calculates a score out of **100** using six different categories:

| Category                     | Maximum Score |
| ---------------------------- | ------------: |
| Technical Skills             |            20 |
| Projects                     |            20 |
| Education                    |            15 |
| Experience & Achievements    |            15 |
| ATS & Resume Quality         |            15 |
| Communication & Presentation |            15 |
| **Total**                    |       **100** |

The score is calculated separately by the application and is not generated by the AI.

## 🤖 AI Analysis

The backend sends the extracted resume text to Google Gemini and requests structured placement-oriented feedback.

The AI provides:

* Professional Summary
* Skills Found
* Strengths
* Missing / Weak Skills
* Project Analysis
* Education Summary
* Suitable Job Roles
* Improvement Suggestions

The backend prompt instructs the AI to use only information actually present in the uploaded resume and avoid inventing projects, skills, experience, certifications, marks, or achievements.

## 🚀 Getting Started

### Frontend Setup

Clone the repository:

```bash
git clone https://github.com/Yuvraj1812006/AI-Resume-Analyzer.git
```

Move into the frontend directory:

```bash
cd AI-Resume-Analyzer/frontend
```

Install Flutter dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

For Chrome:

```bash
flutter run -d chrome
```

## 🌐 Backend

The application uses a Node.js + Express backend to communicate with Google Gemini.

Backend endpoint:

```text
POST /analyze
```

The frontend sends the extracted resume text as JSON:

```json
{
  "resumeText": "Extracted resume text"
}
```

The backend processes the request and returns the AI-generated analysis.

## 🔐 Environment Variables

The Gemini API key is stored securely on the backend using an environment variable.

```env
GEMINI_API_KEY=your_gemini_api_key
```

**Never commit your `.env` file or Gemini API key to GitHub.**
